# Student Management System (C Project)

A C console program that manages student records using a **singly linked list**. Demonstrates conditions, loops, strings, structs, pointers and dynamic memory.

## Features
- Add a student (rejects duplicate IDs, handles allocation failure)
- Display all students
- Search for a student by ID
- Update a student's name, age and GPA
- Delete a student by ID
- Calculate the average GPA
- Find the student with the highest GPA
