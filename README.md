# Embedded Systems Projects

Projects from the **Edges For Training – Standard Embedded Systems Diploma**, built mainly on the **ATmega32** microcontroller (16 MHz) in C.

| # | Project | Folder | Key topics |
|---|---------|--------|------------|
| 1 | Student Management System | [`01-C-Student-Management-System`](01-C-Student-Management-System) | C, structs, pointers, linked lists |
| 2 | Dual-Mode Stopwatch | [`02-Mini-Project-2-Stopwatch`](02-Mini-Project-2-Stopwatch) | Timer1 CTC, external interrupts, multiplexed 7-segment |
| 3 | Smart Home Automation | [`03-Mini-Project-3-Smart-Home`](03-Mini-Project-3-Smart-Home) | ADC, PWM, LCD, LM35, LDR, flame sensor, layered architecture |
| 4 | Car Parking Sensor | [`04-Mini-Project-4-Parking-Sensor`](04-Mini-Project-4-Parking-Sensor) | ICU, ultrasonic HC-SR04, LCD (4-bit), LEDs, buzzer |
| 5 | Vehicle Fault Detection and Logging System | [`05-Final-Project-Vehicle-Fault-Detection`](05-Final-Project-Vehicle-Fault-Detection) | Two-ECU design (HMI + Control), UART, TWI/EEPROM, keypad, LCD |

Each project folder contains a README with the description, the project PDF (task specification), and the source / project files.

## Tools
Proteus (simulation), Eclipse AVR / Atmel toolchain, AVR-GCC.
